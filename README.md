# 1988년 거실

HCI와 커뮤니케이션 2주차 오프라인 실습. 거실 화면에서 라디오·텔레비전·전화기로 들어가
같은 과업을 1988년 기기와 지금의 앱으로 수행하고, 통제감과 인지 부하를 비교한다.

## 돌려보기
    npx serve public          # 또는 python -m http.server 8899

## 배포
    firebase login
    firebase deploy

## 매체 파일
`public/media/radio/` 와 `public/media/tv/` 에 넣는다. 없으면 합성음과 화면으로 대체된다.
