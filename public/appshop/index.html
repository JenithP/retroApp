우리 조를 고르세요

한 조가 여러 기기로 들어와도 됩니다. 설계서는 조원 모두에게 똑같이 보입니다.

교수님이 제작 시작을 누르면 설계서가 열립니다.

설계 방법

앱공방에서는 장면마다 세 칸을 채우며 앱을 설계합니다. AI는 여러분이 적은 내용만 바탕으로 화면을 만듭니다. 버튼, 안내 문구, 되돌리기 기능, 확인 창처럼 필요한 요소가 있다면 반드시 직접 적어 주세요. 적지 않은 것은 자동으로 만들어지지 않습니다.

생성 기회는 조별로 총 번입니다. 30분 뒤 교수님이 앱을 출판하면 그 이후에는 수정할 수 없습니다.

장면은 이렇게 이어집니다

  1. 장면 1은 앱을 켜면 처음 나타나는 화면입니다.
  2. 그 화면에서 사용자가 무언가를 하면(사용자 행동) 앱이 바뀝니다(앱 반응).
  3. 바뀐 뒤의 화면에서 이어지는 일을 장면 2에 적습니다. 이렇게 장면 1 → 2 → 3 … 순서로 적으면 사용자가 앱을 쓰는 흐름이 됩니다.
  4. 같은 화면에서 다른 행동을 할 수도 있다면(예: 「예」와 「아니요」), 행동마다 장면을 하나씩 따로 적고 화면 칸에 「장면 2와 같은 화면」처럼 적어 주세요.
예시 보기 — 물 마시기 기록 앱
화면에 나타나는 것사용자 행동앱 반응
장면 1가운데 큰 글씨로 「오늘 마신 물 0잔」, 그 아래 「한 잔 마셨어요」 버튼「한 잔 마셨어요」를 누른다「한 잔 기록할까요?」라는 글과 「예」 「아니요」 버튼이 있는 창이 뜬다
장면 2장면 1에서 뜬 확인 창「예」를 누른다창이 닫히고 「오늘 마신 물 1잔」으로 바뀐다
장면 3장면 2와 같은 확인 창「아니요」를 누른다창만 닫히고 숫자는 그대로다

장면 2와 3은 같은 창에서 서로 다른 행동을 한 경우입니다. 만약 장면 3을 적지 않았다면, 「아니요」 버튼은 눌러도 아무 일이 일어나지 않습니다.

평가 방법 (눌러서 접기 · 펼치기)
① 평가할 앱의 미션 카드
앱을 만든 조, 앱 이름, 사용자, 시간, 해야 할 일, 사용 상황, 사용자 특징을 확인합니다. 카드 맨 아래에는 초록색 굵은 글씨로 평가 과업이 표시됩니다.
② 과업 진행 버튼
「과업 시작」을 누른 뒤, 과업을 마치면 「과업 끝냄」을 누릅니다. 더 이상 진행하기 어렵다면 「포기」를 누를 수 있습니다. 옆에는 걸린 시간과 앱 안에서 누른 횟수가 자동으로 기록됩니다.
③ 폰 화면
다른 조가 출판한 앱을 실제로 사용해 보는 공간입니다. 진행하다가 막히면 「처음 화면으로 다시 켜기」를 눌러 처음부터 다시 시작할 수 있습니다.
④ 문제 기록하기
사용하다가 불편하거나 이상한 점을 발견할 때마다 기록합니다. 어느 화면에서 생긴 문제인지, 닐슨의 10가지 사용성 원칙 중 어떤 원칙에 해당하는지, 얼마나 심각한지(0점 문제 아님 ~ 4점 출시 전 반드시 고쳐야 할 문제)를 고르고 한 줄로 적습니다.
⑤ 사용 후 평가하기
앱을 모두 사용한 뒤 실용적 품질과 쾌락적 품질을 1–7점으로 평가하고, 한 줄 소감을 적습니다.
⑥ 평가 보내기
과업을 끝내거나 포기한 뒤, 두 품질 점수를 모두 선택하면 「평가 보내기」를 누를 수 있습니다. 평가를 보내면 앱 목록으로 돌아가며, 해당 앱 카드에 「평가를 보냈습니다」라고 표시됩니다.
