Tripo 에서 만든 GLB 모델을 이 폴더에 넣으면 게임이 알아서 블록 인형 대신 씁니다.
(원본은 ../시간여행_모델 폴더에 넣고 python tools/optimize_models.py 를 돌리면
 크기를 줄여 여기로 들어옵니다.)

  student1.glb ~ student4.glb   시작 화면에서 고르는 주인공 넷
                                 (student.glb 하나만 넣으면 넷 다 같은 모습)
  nu.glb        원시인 소년 「빠른 발 누」
  elder.glb     병든 마을 노인
  woman.glb     마을 여성
  hunter.glb    마을 사냥꾼
  kid.glb       마을 아이

뼈대(리깅)만 넣어 주시면 걷기·갸웃·만세 같은 동작은 게임이 만들어 냅니다.
동작(애니메이션)까지 들어 있으면 그걸 씁니다.
파일이 없으면 블록 인형 그대로 나옵니다.
